fullstack · java · javascript 2026

restaurante pedacinhos de maria - sistema completo de pedidos para restaurante

um sistema completo de pedidos e operação criado para resolver um problema real e cotidiano de um pequeno restaurante familiar: os clientes precisavam ouvir o cardápio em voz alta, um por um, todos os dias, e a cozinha dependia de alguém levar o pedido fisicamente até lá. o que começou como um cardápio com qr code virou um sistema completo, com painel de cozinha ao vivo, contas de funcionários com acesso por perfil aprovadas pelo dono e sincronização de pedidos em tempo real, atualmente implantado e em uso.

cardápio digital com qr code, sem necessidade de login para os clientes painel de cozinha em tempo real com fila de pedidos ao vivo atualização do status dos pedidos ao vivo (websocket/stomp) autenticação jwt com controle de acesso por perfil (funcionário vs. dono) painel administrativo interno para aprovar/rejeitar contas de funcionários api rest documentada com openapi/swagger backend dockerizado com deploy na render mongodb atlas com retenção de dados via índices ttl quatro frontends independentes, sem frameworks testes unitários com junit5 + mockito organização modular do backend por funcionalidade (auth, menu, order) integração com a whatsapp cloud api para notificações de pedido pronto tratamento de exceções centralizado e estruturado
